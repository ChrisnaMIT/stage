# Faire circuler le savoir-faire

Reportage de mon stage de deuxième année chez **Swiss Désembouage**, réalisé dans le cadre de mon Bachelor Concepteur Développeur d’Applications à l’ESD Lyon.

Le site présente l’entreprise, le contexte du projet, mes missions, les difficultés rencontrées et les compétences mobilisées pour repenser sa présence en ligne.

## Technologies

- React
- TypeScript
- Vite
- CSS
- GitHub Pages

## Lancer le projet

```bash
npm install
npm run dev
```

## Construire la version de production

```bash
npm run build
```
